# Uganda-Digital-MathTool-Kit
Uganda Digital MathTool Kit (UDMTK) is an offline interactive mathematics learning resource developed for Uganda's competency-based lower secondary mathematics curriculum.
Version 1.0 covers Senior 1–Senior 4 Mathematics and includes interactive Explore, Discover, Practice and Apply activities, competency-based assessment scenarios, a scientific calculator, examination practice, and the interactive UDMTK MathLab.
Key features:
• Senior 1–Senior 4 Mathematics
• Competency-based learning activities
• Interactive mathematical manipulatives
• UDMTK MathLab for graphing and geometry
• Scientific calculator
• Senior 4 examination practice
• Fully usable without internet after installation
• Designed for Windows computers
This download is a 30-day trial version.
