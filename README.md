# Uganda Digital MathTool Kit (UDMTK)

Interactive, offline mathematics learning for Uganda's competency-based lower secondary curriculum — Senior 1 to Senior 4.

## Download

[**Download UDMTK v1.0 — Windows 30-Day Trial**](https://github.com/ndungoissa/Uganda-Digital-MathTool-Kit/releases/latest/download/UDMTK_v1.0_Setup.exe)

### Key features
- Senior 1–Senior 4 Mathematics
- Explore, Discover, Practice and Apply activities
- Interactive mathematical manipulatives
- UDMTK MathLab
- Scientific calculator
- Senior 4 examination practice
- Offline use after installation

### Installation
1. Download `UDMTK_v1.0_Setup.exe`.
2. Run the installer.
3. Follow the installation wizard.
4. Launch Uganda Digital MathTool Kit.
